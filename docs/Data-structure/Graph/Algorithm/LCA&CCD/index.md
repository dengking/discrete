# LCA&CCD

## 树结构「概念对偶」：最近公共后代（CCD）

这是和LCA在“祖先-后代”维度完全对称的概念，二者严格对应：

| 概念  | 全称                                 | 定义                                      | 存在性                 |
| --- | ---------------------------------- | --------------------------------------- | ------------------- |
| LCA | Lowest Common Ancestor   最近公共祖先    | 两个节点所有公共祖先中，**深度最大、离节点最近**的那个（最靠下的公共祖先） | 有根树中一定存在            |
| CCD | Closest Common Descendant   最近公共后代 | 两个节点所有公共后代中，**深度最小、离节点最近**的那个（最靠上的公共后代） | 不一定存在（不同分支的叶子无公共后代） |

在有向无环图（DAG）中，也叫**最近公共后继**。

## 算法/字符串领域「经典对应」：最长公共前缀（LCP）

这是后缀树中最经典的绑定关系，也是算法题、面试中最常和LCA一起出现的对应概念：

> 后缀树上，两个字符串对应的叶子节点，它们的**LCA的路径长度**，恰好等于这两个字符串的**LCP（Longest Common Prefix，最长公共前缀）的长度**。

因此在字符串、后缀树语境下，LCA 天然对应 LCP。

> wikipedia [Suffix tree](https://en.wikipedia.org/wiki/Suffix_tree) 

## 补充：格论视角（衔接不动点知识）

在树对应的偏序格中（约定 `u ≤ v` 表示u是v的祖先）：

- LCA 等价于两个元素的 **下确界（infimum, inf）**，对应格的**交运算**；
- CCD等价于两个元素的 **上确界（supremum, sup）**，对应格的**并运算**；
