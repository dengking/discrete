# 如何"看见"一个格

前三节都在讲结构；这节只讲**图像**。核心就一句话：

> **格 = 一个"任意两个东西都有唯一最佳上界和唯一最佳下界"的世界。**
> 
> 也就是：**永远有唯一的最小妥协，永远有唯一的最大共识。**

不是"有上界"，是"有**唯一最小**的上界"。这个"唯一"就是全部苛刻之处。

---

## 一、入门图像：约数

拿 $30$ 的所有约数，按**整除**排：

```
              30
          /   |   \
        6     10    15
        |  \ /  \  /  |
        |   X    X    |
        |  / \  / \   |
        2    3     5
          \  |  /
             1
```

- $x\vee y=\mathrm{lcm}$，$x\wedge y=\gcd$
- $\bot=1$，$\top=30$
- $6\vee 10=30$，$6\wedge 10=2$

**这个立方体你在上一节见过**——它就是 $2^{\{2,3,5\}}$。质因数就是"元素"，整除就是"包含"。所以**幂集格的第一个具身化，是算术**。

小小的启发：$\gcd$ 和 $\mathrm{lcm}$ 你从小学就在用，那时你已经在用格了。格论只是说："凡是有 gcd/lcm 这种配对的地方，都能套同一批定理。"

> GCD=greatest-common-divisor=最大公约数 
> 
> LCM=least-common-multiple=最小公倍数

## 二、名字的由来：它真的长得像"格子"

取两个格作乘积，就得到**网格**。看 $\mathbb N\times\mathbb N$：

```
  y
  4 │   x •─────────• x∨y = (3,4)
    │     │         │
  3 │     │         │
    │     │         │
  2 │     •─────────• y = (3,2)
    │  x∧y = (1,2)
  1 │
    └──────────────────► x
        1    2    3
```

**$x\vee y$ 和 $x\wedge y$ 就是 $x,y$ 张成的那个矩形的另外两个角。**

$\vee$ = 逐坐标取 max（右上角），$\wedge$ = 逐坐标取 min（左下角）。

这是"格"这个中文译名的来源（英文 lattice 同）：**Hasse 图看起来像窗棂、像格栅**。而且这个图像有实质内容：

> **有限分配格 = 局部处处像这张网格的东西。**（第七节会看到反面）

现实中的例子：**向量时钟** $\mathbb N^n$ 就是这个网格，$\vee$ = 逐分量 max，正是分布式系统里合并两个时钟的操作。

## 三、核心动作：把 Hasse 图当水管

这是我认为最好用的动态图像。

> 把 Hasse 图想成一套管道。从 $x$ 和 $y$ 同时往**上**放水，水沿所有向上的边扩散。
> **$x\vee y$ = 两股水第一次必然汇合的那个点。**

```
              ● ← 两股水在这里第一次相遇 = x ∨ y
             ╱ ╲
            ╱   ╲
           x     y
```

反过来往下放水，第一次汇合处就是 $x\wedge y$。

**格的条件 = "第一次汇合的地方唯一"。** 如果水分头往上走，出现两个互不可比的"最早汇合点"，就不是格：

```
        c       d        ← 两个极小上界，谁都不比谁小
        │╲     ╱│
        │ ╲   ╱ │
        │  ╲ ╱  │
        │   ╳   │
        │  ╱ ╲  │
        a       b
```

$a,b$ 的上界有 $c$ 和 $d$，但没有**最小**的。$a\vee b$ 不存在 ⇒ 不是格。

注意：**加个 $\top$ 也救不回来**（上界变成 $\{c,d,\top\}$，最小的还是没有）。这个"蝴蝶结"就是最典型的非格。

## 四、现实中"不是格"会出什么事

### Git 的十字交叉合并（criss-cross merge）

提交历史是 DAG，`merge base` = 两个分支的**最近公共祖先** = meet。平时它是唯一的，但：

```
        A       B          ← 两个不同的公共祖先，互不可比
        │╲     ╱│
        │ ╲   ╱ │
        │  ╲ ╱  │
        │   ╳   │
        │  ╱ ╲  │
        C       D          ← 要合并的两个分支
```

$C$ 和 $D$ 的极大公共祖先有 **$A$ 和 $B$ 两个**，$C\wedge D$ 不存在。Git 此时无法"取一个 base 做三方合并"，只能启用 `recursive` 策略：先把 $A,B$ 递归合并成一个虚拟 base，再用它。

**"不是格"不是抽象缺陷，它直接变成了 git 里一个真实的、需要专门算法应付的麻烦。**

### 目录树：只有半个格

路径按前缀序（`/` 最小，越深越大）：

```
                    /a/b/c        /a/b/d
                        ╲          ╱
                         ╲        ╱
                          /a/b            ← meet 存在：最长公共前缀
                            │
                           /a
                            │
                            /
```

- **$\wedge$ 永远存在**（最长公共前缀）⇒ 交半格 ✓
- **$\vee$ 通常不存在**（`/a/b/c` 和 `/a/b/d` 没有"最小公共延伸"）✗

标准修补：**硬加一个 $\top$ 叫"矛盾 / conflict / 类型错误"**。于是 $\vee$ 恒存在，成为格。

> 这正是类型合一、约束求解、抽象解释里 $\top$ 的真身：**$\top$ 不是"什么都是"，$\top$ 是"你要求的东西互相打架了"。** 很多人一开始不理解为什么类型格顶上要放一个奇怪的 `Any`/`⊤`，答案就是"为了把半格补成格"。

## 五、上下方向到底是什么意思

这是最容易混乱、也最有用的一层直觉。记住：

> **越往上 = 约束越少 = 可能性越多 = 你知道得越少。**
> **越往下 = 约束越多 = 越具体 = 信息越精确。**

| 领域   | $\bot$（下）          | $\top$（上）          | $x\vee y$ | $x\wedge y$ |
| ---- | ------------------ | ------------------ | --------- | ----------- |
| 子集构造 | $\varnothing$（不可能） | $Q$（哪都可能）          | 保守合并两种可能  | 同时满足        |
| 类型   | `Never`            | `Any`              | 最小公共超类    | 交类型         |
| 区间分析 | $\bot$（不可达）        | $(-\infty,\infty)$ | 包住两者的最小区间 | 交集          |
| 权限   | 无权限                | 最高密级               | 合并两个标签    | 共同权限        |
| 逻辑   | `false`            | `true`             | 或         | 且           |

于是那个水流图像变成一句实践口号：

> **$\vee$ = 分支汇合处的"保守放弃精度"；$\wedge$ = 累积约束。**

程序分析里 `if (c) x=1; else x=2;` 之后 $x\in\{1\}\vee\{2\}$，你被迫上升到"$x$ 是 1 或 2"甚至"$x$ 未知"。**每一次 join，都是一次信息损失。** 格论量化的就是这个损失。

⚠️ **方向是约定，不同书相反**。数据流分析里很多教材把 $\top$ 当"未知"（如上表），也有把 $\bot$ 当"未知"的。看到 lattice 先问一句"哪头是不知道"，能省掉大半困惑。

## 六、$\bot$ 和 $\top$ 的形象：地板和天花板

```
        ⊤   ← 天花板：所有向上的路的终点。"什么都可能" / "矛盾"
        ⋮
        ⋮        高度 = 从地板到天花板最长的一条链
        ⋮        ← 这个数字 = 迭代算法的步数上界
        ⋮
        ⊥   ← 地板：所有向下的路的终点。"不可能" / "无信息"
```

**格的高度 = 楼有几层。** 这是所有不动点算法终止性的唯一来源：往上灌水，水位只升不降，撞到天花板必停。

这也解释了为什么区间分析 $[-\infty,\infty]$ 上的区间格**高度无穷**（$[0,0]\subset[0,1]\subset[0,2]\subset\cdots$），所以 `while (i<n) i++;` 会让迭代永不终止——必须引入**加宽（widening $\nabla$）**：不再一层层爬，而是**直接坐电梯冲到顶**（$[0,1]\nabla[0,2]=[0,\infty)$）。

> 加宽的形象：**楼太高爬不完，那就跳楼梯，跳过头了再用收窄（narrowing）往回走两步。**

## 七、分配律的图像：**不要过冲**

非分配长什么样？只有两种基本形状（Birkhoff 判据）。

### 钻石 $M_3$：一 join 就冲上天

```
        1
      / | \
     a  b  c        三个原子彼此毫无关系
      \ | /
        0
```

$a\wedge(b\vee c)=a\wedge 1=a$，但 $(a\wedge b)\vee(a\wedge c)=0\vee 0=0$。

**几何实体：过原点的三条不同直线（在同一平面内）。**

```
         平面 (= b∨c，也 = a∨b = a∨c)
        ╱  │  ╲
       a   b   c        ← 三条共面直线
        ╲  │  ╱
          原点
```

$b$ 和 $c$ 一 join 就**张成了整个平面**——而平面里还躺着 $a$。所以 $a$ 被顺带捞了进来。但 $a$ 和 $b$、$a$ 和 $c$ 分别看，交集都只是原点。

> **这就是"过冲"（overshoot）：合并两条信息时，结果比"两条信息各自的贡献之和"要多。**
> **分配律 = 合并时不会凭空多出东西。**

### 五边形 $N_5$：一条不对称的旁路

```
          1
        ╱   ╲
       b     ╲
       │      c      ← c 是一条"抄近道"的旁路
       a     ╱
        ╲   ╱
          0
```

$a<b$，但 $a\vee(c\wedge b)=a\vee 0=a$，而 $(a\vee c)\wedge b=1\wedge b=b$。

**$c$ 从底一步跨到顶，把 $a<b$ 这段落差"短路"了。** 非模格的典型形状——不同的路径长度不一致，"维数/秩"的概念在这里失效。

### 于是判定法变得很视觉

> **拿到一个 Hasse 图，就在里面找钻石和五边形。**
> 
> - 找到 $N_5$ ⇒ 非模。
> - 找到 $M_3$ 或 $N_5$ ⇒ 非分配。
> - 都找不到 ⇒ 分配。

### 一个从 $n=3$ 就翻车的例子

集合 $\{a,b,c\}$ 的所有**分组方式**（划分格 $\Pi_3$，越往上分得越粗）：

```
           {abc}
         ╱   |   ╲
   {ab|c} {ac|b} {a|bc}
         ╲   |   ╱
          {a|b|c}
```

**这就是 $M_3$。** 任意两种"两块划分"往上一合并就直接变成"全在一起"，冲过头了。

> 这解释了上一节那句话的实感：**子集构造活在超立方体（分配、漂亮）里，DFA 最小化活在划分格（从 3 个元素起就是钻石）里。** 后者算法更难看，不是巧合。

## 八、有限分配格 = 楼梯

Birkhoff 定理的图像版。在超立方体 $2^{\{a,b,c\}}$ 里，如果元素之间有依赖关系"想要 $b$ 必须先有 $a$"，那么合法的集合族就是一个**楼梯形的下闭区域**：

```
   超立方体全貌            加上约束 a≺b 后剩下的
      {abc}                     {abc}
     ╱  |  ╲                    ╱   ╲
  {ab} {ac} {bc}             {ab}   {ac}
    |  ╲╱  ╲╱ |                 ╲   ╱
   {a}  {b}  {c}               {a}      {c}   ← {b} 被砍掉了
     ╲   |   ╱                   ╲     ╱
        ∅                           ∅
```

> **有限分配格 = 从超立方体上按"楼梯线"切下来的一块。**
> 切法（= 偏序 $P$）与形状（= 格 $L$）一一对应。

这是"分配格 = 偏序集的另一种画法"的可视版。杨氏图（Young diagram）、任务调度的可行前缀集、Datalog 的最小模型，都是这个图像。

## 九、完备 = 无限股水流也能汇合，中间没有洞

有限格不用操心。无限时，"完备"的图像是：

```
   不完备（有洞）：ℚ ∩ [0,1]

   0 ────•─•─•─•─•─ ✗ ─•──•───────── 1
         往上逼近 √2/2 ┘
         水流一直挤过去，但那个点不在格里
```

$\mathbb Q\cap[0,1]$ 任意**两**个元素都有 max/min，是格；但**无穷多股水流可以汇聚到一个不存在的地方**。填上所有洞（Dedekind 完备化）就得到 $[0,1]$。

> **格 = 两股水能汇合；完备格 = 任意多股水都能汇合，且汇合点一定在格内。**

完备格自动有 $\bot,\top$（空集的 sup / inf）。而且只需检查一半：**任意 sup 存在 ⇒ 任意 inf 自动存在**（"下界集的 sup"）。图像上：天花板方向封死了，地板方向也就自动封死了。

## 十、不动点 = 灌水

回到你最初的问题，用这套图像重讲一遍：

```
        ⊤ ────────────────  天花板（有限高度 ⇒ 必停）
        │
        │            ⋮
        │     F³(⊥) ─┼─  第 3 次迭代
        │     F²(⊥) ─┤
        │      F(⊥) ─┤
        ⊥ ───────────┘   从地板开始灌水
```

- $F$ 单调 = **水位只升不降**
- 有限高度 = **一定撞到某层就不动了**
- **lfp = 灌水停下来的水位线**
- **gfp = 从天花板往下漏，漏到停下来的位置**

$\varepsilon$-闭包：把 $\varepsilon$ 边当水管，从初始状态集**往外泼水**，能湿到哪算哪，湿完为止。

而"lfp vs gfp"的图像差别：

```
   ε-自环：   1        2⟲
              ↑ 从 {1} 泼水

   lfp = {1}       ← 水没流到 2，2 是干的  ✓
   gfp = {1,2}     ← 2 的水"自己养活自己"（自己流给自己）✗
```

> **lfp = 只承认有源头的水；gfp = 允许自循环凭空维持。**
> 归纳性质（可达、终止、有穷字接受）用 lfp；共归纳性质（不变式、安全性、双模拟、无穷字）用 gfp。

## 十二、三句话装进脑子

1. **格 = 永远有唯一最佳折中的世界。**看到偏序，先问："任两点的最早汇合点唯一吗？"不唯一（蝴蝶结）就不是格，你的算法会像 git 一样需要特殊处理。

2. **上下方向 = 信息多少。**$\vee$ 是分支汇合时的保守放弃，$\wedge$ 是约束累积。每次 $\vee$ 都在损失精度——**分配律恰好是"损失不会额外过冲"的保证**，这就是 MFP=MOP 与只能过近似的分水岭。

3. **算法 = 灌水。**单调保证水位不倒流，有限高度保证会停，Tarski 保证停在正确的地方。$\varepsilon$-闭包、子集构造、数据流分析、Datalog、模型检验，全是同一桶水。

> 最后一个总图像：**幂集格是最平整的那块地（超立方体，处处像网格）；每引入一个闭包算子（span、生成、传递闭包、$\varepsilon$-闭包、演绎），就相当于把这块地上的某些点"吸附"到别处，地面开始起皱——起皱的第一个症状就是钻石 $M_3$ 冒出来，分配性失守。所有"有趣但难算"的格，都是这么皱出来的。**

# 格（Lattice）：一个结构的两副面孔

上一节的 $2^Q$ 是格的**极端最优个例**；本节退回一般情形，看清"格"这个概念本身提供了什么、以及丢掉 $2^Q$ 的各项奢侈性质之后会发生什么。

> ⚠️ **术语歧义警告**：本文的 lattice = **序论意义的格**。密码学/数论里的 "lattice" 指 $\mathbb R^n$ 中的离散子群 $\Lambda=\{\sum a_ib_i\mid a_i\in\mathbb Z\}$（LLL、LWE、格基归约），与本文**毫无关系**，只是英文撞名。中文有时用"格子/点阵"区分。

---

## 一、两个定义，与它们的等价

### (A) 序理论定义

偏序集 $(L,\le)$，使任意两元 $x,y$ 都有上确界 $x\vee y$（join）与下确界 $x\wedge y$（meet）。

### (B) 代数定义

代数 $(L,\vee,\wedge)$，两个二元运算满足：

| 律      | $\vee$                           | $\wedge$                                 |
| ------ | -------------------------------- | ---------------------------------------- |
| 交换     | $x\vee y=y\vee x$                | $x\wedge y=y\wedge x$                    |
| 结合     | $(x\vee y)\vee z=x\vee(y\vee z)$ | $(x\wedge y)\wedge z=x\wedge(y\wedge z)$ |
| **吸收** | $x\vee(x\wedge y)=x$             | $x\wedge(x\vee y)=x$                     |

（幂等律 $x\vee x=x$ 可从两条吸收律推出，无需公设。）

### 等价

- (A)⇒(B)：直接验证。
- (B)⇒(A)：定义 $x\le y\iff x\vee y=y$。吸收律保证这与 $x\wedge y=x$ 等价；再验证 $\le$ 是偏序且 $\vee,\wedge$ 给出 sup/inf。

**这个等价不是废话，它是格论最重要的元事实**：

> 格既是**偏序集**（可以谈 Hasse 图、链、高度、区间、对偶），又是**等式定义的代数**（equational class = **variety**）。

作为 variety，格自动获得整套普遍代数机械：子格、同态、同余、直积、子直积、**自由格**、Birkhoff HSP 定理、Mal'cev 条件。这是"格"比"任意偏序集"强大得多的根本原因——而这也是**完备格不是 variety**（涉及无限元运算）从而行为迥异的原因，见第三节的坑。

### 对偶原理

$(L,\le)$ 是格 $\iff$ $(L,\ge)$ 是格，且 $\vee\leftrightarrow\wedge$。**任何格论定理，把 $\le,\vee,\wedge,0,1$ 全部翻转，仍是定理。**（$2^Q$ 更强：它自身**自对偶**，$S\mapsto S^c$。一般格只有"定理层面"的对偶，没有"对象层面"的自同构。）

### 两个容易漏掉的小定理

**1. 完备并半格 = 完备格。** 若任意 sup 存在，则任意 inf 自动存在：
$$\bigwedge S=\bigvee\{x\in L\mid \forall s\in S,\ x\le s\}$$
（"下界集的上确界"）。所以定义完备格只需说一半。$\varnothing$ 的情形给出 $\bigvee\varnothing=0$、$\bigwedge\varnothing=1$，故完备格自动有界。

**2. 有限格必完备。** 因此"有限性 ⇒ Kleene 迭代终止"（上一节反复用到的事实）不依赖任何特殊结构。

## 三、四个必须记住的坑

**(1) 有界 + 格 $\ne$ 完备。**
$L=\mathbb Q\cap[0,1]$：任意两元有 max/min，有 $0,1$，但 $S=\{q\mid q^2<\tfrac12\}$ 在 $L$ 中无上确界（$\sqrt2/2\notin\mathbb Q$）。这就是为什么实数分析要 $\mathbb R$、为什么 Dedekind 完备化（第五节）有必要。

**(2) 完备格的子格不必完备；格同态不必保任意 sup。**
$\mathbb Q\cap[0,1]$ 是完备格 $[0,1]$ 的子格但不完备。所以要区分：

- **子格**（对二元 $\vee,\wedge$ 封闭）
- **完备子格**（对任意 $\bigvee,\bigwedge$ 封闭）

上一节 "$\varepsilon$-饱和集构成 $2^Q$ 的完备子格" 用的是后者，且其 $\vee$ **不是**并集——正是这一点埋下了非分配的种子。

**(3) 保序 $\ne$ 格同态。**
$f$ 保序只给 $f(x\vee y)\ge f(x)\vee f(y)$。例：$f:2^{\{a,b\}}\to\mathbf 2$，$f(S)=[|S|=2]$ 保序，但 $f(\{a\}\vee\{b\})=1\ne 0=f(\{a\})\vee f(\{b\})$。
**这个"$\ge$ 而非 $=$"的间隙就是程序分析里 MFP 与 MOP 的差距**（第八节）。

**(4) 模律不能去掉前提。** 模律是 $x\le z\Rightarrow x\vee(y\wedge z)=(x\vee y)\wedge z$；去掉 $x\le z$ 就成了分配律的一部分，是更强的要求。

## 四、恒等式层级：格 ⊃ 模格 ⊃ 分配格 ⊃ 布尔代数

| 类               | 附加公理                                                   |
| --------------- | ------------------------------------------------------ |
| 格               | —                                                      |
| **模格**（modular） | $x\le z\Rightarrow x\vee(y\wedge z)=(x\vee y)\wedge z$ |
| **分配格**         | $x\wedge(y\vee z)=(x\wedge y)\vee(x\wedge z)$          |
| **Heyting 代数**  | 有界分配 + 存在 $x\to y$（即 $x\wedge(-)$ 有右伴随）                |
| **布尔代数**        | 有界分配 + 每元有补                                            |

- 在格中，两条分配律**互推**（$\wedge$ 对 $\vee$ 分配 $\iff$ $\vee$ 对 $\wedge$ 分配）。在一般偏序集里不然。
- 分配 ⇒ 模。反之不然。
- 分配格中**补唯一**（若存在）。布尔代数中因此 $\neg$ 是良定义的对合。
- Heyting：$x\to y$ 存在 $\iff$ 分配（完备情形下），$\neg x:=x\to 0$ 只是伪补，$x\vee\neg x=1$ 未必成立 ⇒ **直觉主义逻辑的代数语义**。布尔 = Heyting + 排中律。

### 两个禁用子格：Birkhoff 判据

$$M_3\ (\text{钻石}) \qquad\qquad N_5\ (\text{五边形})$$

```
      1                        1
    / | \                     / \
   a  b  c                   b   \
    \ | /                     |    c
      0                       a   /
                               \ /
                                0
```

> **定理（Dedekind / Birkhoff）**
> 
> - $L$ **模** $\iff$ $L$ 不含同构于 $N_5$ 的子格。
> - $L$ **分配** $\iff$ $L$ 不含同构于 $N_5$ 或 $M_3$ 的子格。

检验：

- $M_3$：$a\wedge(b\vee c)=a\wedge 1=a$，但 $(a\wedge b)\vee(a\wedge c)=0$。**非分配，但是模的**。
- $N_5$：$a\le b$，$a\vee(c\wedge b)=a\vee 0=a$，但 $(a\vee c)\wedge b=1\wedge b=b\ne a$。**非模**。

**这是格论最实用的工具之一**：判断一个格是否分配，只需在 Hasse 图上找钻石和五边形。

### 再往下：半模格与几何格

| 类                       | 条件                                           | 代表              |
| ----------------------- | -------------------------------------------- | --------------- |
| 上半模                     | $x\wedge y\prec x\Rightarrow y\prec x\vee y$ | 拟阵格             |
| 几何格                     | 上半模 + 原子的 + 有限长                              | $\iff$ 单纯拟阵的闭集格 |
| **Jordan–Dedekind 链条件** | 所有极大链等长（半模 ⇒ 此条件 ⇒ 分级）                       | 子空间格、划分格        |

模 ⇒ 上下半模都成立 ⇒ JD 条件。这是"维数/秩"概念能存在的格论条件。

## 五、表示定理：格"实际上"长什么样

### (1) Birkhoff 有限分配格表示定理 ★

> 每个**有限分配格** $L$ 同构于某有限偏序集 $P$ 的**下集格** $\mathcal O(P)$（下闭子集，序为 $\subseteq$）；取 $P=J(L)$ = $L$ 的并不可约元（继承 $L$ 的序）。
> 
> 更强：$L\mapsto J(L)$ 与 $P\mapsto\mathcal O(P)$ 给出**有限分配格范畴与有限偏序集范畴的对偶等价**。

推论：

- $|L|$ = $P$ 的反链个数（下集 ↔ 反链，取极大元）。
- 若 $P$ 无关系（离散），$\mathcal O(P)=2^P$ ⇒ **有限布尔代数 $\cong 2^n$**（上一节的定理是这里的特例）。
- **有限分配格 = 有限偏序集的"同一件事"**。所以分配格论本质上是组合序理论。

### (2) 无限情形：Stone / Priestley 对偶

| 代数侧                   | 空间侧                          |
| --------------------- | ---------------------------- |
| 布尔代数                  | Stone 空间（紧 Hausdorff 完全不连通）  |
| 有界分配格                 | Priestley 空间（Stone 空间 + 闭偏序） |
| frame（完备 + 有限交对任意并分配） | 局部（locale）；空间侧 = 拓扑空间的"无点版"  |
| Heyting 代数            | Esakia 空间                    |

代数侧的元素 ↔ 空间侧的紧开集；理想/滤子 ↔ 点。**这是"逻辑 ↔ 拓扑"整条对偶线的源头。**

### (3) 每个完备格都是概念格（Birkhoff）

给形式背景 $(G,M,I)$（对象、属性、关系），由 Galois 连接 $A\mapsto A'$、$B\mapsto B'$ 得到的**形式概念** $(A,B)$（$A'=B,B'=A$）在包含序下构成完备格；且

> **每个完备格同构于某个背景的概念格。**

等价说法：**每个完备格都同构于某个 $2^Q$ 上闭包算子的不动点格**。这就完成了上一节结尾的断言——$2^Q$ 是"母格"，其他格全是它的闭子集族，而分配性正是在"$\vee_{\mathcal C}=c(\bigcup\cdot)\ne\bigcup$"这一步丢掉的。

### (4) 划分格与 Whitman 嵌入定理

$\Pi(A)$ = 集合 $A$ 上所有等价关系（按加细序）。它是完备格，$\wedge=\cap$，$\vee$ = 传递闭包（**不是** $\cup$！这里又是"取闭包"）。

> **Whitman**：每个格都可嵌入某个 $\Pi(A)$。（有限格可嵌入有限划分格 —— Pudlák–Tůma 1980。）

所以**划分格"任意坏"**：非模、非分配都在其中。$\Pi(3)$ 就已经是 $M_3$ 加一层，$\Pi(4)$ 含 $N_5$。

**这条与自动机直接相关**：DFA 最小化在 $\Pi(\text{States})$ 中寻找最大的"良好同余"，即 gfp。它之所以比子集构造"难看"（需要 Hopcroft 的精细划分技巧，而不是简单的 worklist 并集），正因为 $\Pi$ 不分配、$\vee$ 要取传递闭包。

### (5) Dedekind–MacNeille 完备化

任意偏序集 $P$ 嵌入一个**最小**完备格 $\mathcal N(P)$（由 Galois 连接 $A\mapsto A^{u\ell}$ 的"截"构成），保持已有的所有 sup/inf。$P=\mathbb Q$ 时给出 $\mathbb R$（加 $\pm\infty$）。这是"任何偏序集都能补成完备格"的标准手段——抽象解释里给一个不完备抽象域"补顶"就是它的粗糙版本。

### (6) 自由格：一个惊人的对比

| 自由对象              | 大小                           |
| ----------------- | ---------------------------- |
| 自由格 $FL(1),FL(2)$ | $1,\ 4$                      |
| **自由格 $FL(3)$**   | **无限**（且含 $FL(\omega)$ 的副本！） |
| 自由**分配**格 $FD(n)$ | 有限；$                         |
| 自由布尔代数 $FB(n)$    | $2^{2^n}$                    |
| **自由完备并半格**       | $2^Q$（上一节的普遍性质）              |

$FL(3)$ 无限意味着格的等式理论极其丰富。好消息：$FL(n)$ 的**字问题可解**（Whitman 条件给出判定算法）。

### (7) 同余格

- **Funayama–Nakayama**：任何格 $L$ 的同余格 $\mathrm{Con}(L)$ 是**分配**的（甚至是 frame）。
- **Grätzer–Schmidt**：每个**代数格**同构于某个代数的同余格。

## 六、完备格：不动点、Galois 连接、闭包算子

这一节是前两轮对话的通用背景。设 $L$ 完备。

### Knaster–Tarski

单调 $F:L\to L$ 有
$$\mathrm{lfp}\,F=\bigwedge\{x\mid F(x)\le x\},\qquad \mathrm{gfp}\,F=\bigvee\{x\mid x\le F(x)\}$$
且 $\mathrm{Fix}(F)$ 本身是**完备格**（但一般不是 $L$ 的子格）。

**Kleene 版**需要更多假设：

- $L$ 有限高度 / $F$ 满足 ACC ⇒ $\bigvee_n F^n(0)$ 有限步稳定；
- $L$ 是 **dcpo** 且 $F$ **Scott 连续**（保有向 sup）⇒ $\mathrm{lfp}\,F=\bigvee_n F^n(0)$；
- 只单调不连续 ⇒ 需**序数迭代** $F^\alpha(0)$。

### Galois 连接 / 伴随

$f:L\to M$、$g:M\to L$ 满足 $f(x)\le y\iff x\le g(y)$。则
$$g\circ f\ \text{是闭包算子},\qquad f\circ g\ \text{是核算子}$$

> **完备格上的伴随函子定理**：$f$ 有右伴随 $\iff$ $f$ 保**任意** sup；$g$ 有左伴随 $\iff$ $g$ 保任意 inf。

这解释了上一节 "$\mathrm{post}_\varepsilon$ 保任意并所以良性" 的地位：它是左伴随。也解释了 $\exists_f\dashv f^{-1}\dashv\forall_f$。

### 闭包算子 ↔ Moore 族（重复但关键）

$c$ 单调 + 增长 + 幂等 $\iff$ 其不动点族对任意 $\bigwedge$ 封闭。不动点格的 $\vee$ 是 $c(\bigvee\cdot)$。

**分配性从这里开始丢失**：

| 闭包算子（在 $2^Q$ 上）           | 不动点格      | 分配？                  |
| ------------------------- | --------- | -------------------- |
| $\varepsilon\text{-cl}$   | ε-饱和集     | 视 NFA 而定             |
| $\mathrm{span}$（线性）       | 子空间格      | 模，**不分配**            |
| 群生成 $\langle\cdot\rangle$ | 子群格       | **非模**               |
| 传递+等价闭包                   | 划分格 $\Pi$ | **非模**               |
| 演绎闭包 $\mathrm{Th}$        | 理论格       | 非分配                  |
| 拓扑闭包                      | 闭集格       | frame 的对偶（有限并对任意交分配） |

## 七、序拓扑与域论（连续格）

CS 语义学需要"无限对象的逼近"，于是有一条平行的层级：

| 结构                     | 条件                                                                 |
| ---------------------- | ------------------------------------------------------------------ |
| **dcpo**               | 每个有向子集有 sup                                                        |
| **cpo / pointed dcpo** | dcpo + 有 $\bot$                                                    |
| **代数格**                | 完备 + 每元是紧元（compact，$x\le\bigvee D\Rightarrow x\le d$ 某 $d$）的有向 sup |
| **连续格**                | 完备 + 每元 $=\bigvee\{y\mid y\ll x\}$（way-below 关系）                   |

- **Scott 拓扑**：开集 = 上闭且对有向 sup 不可达。**Scott 连续 = 拓扑连续 = 保有向 sup**。
- **Kleene 不动点定理**：cpo 上 Scott 连续 $F$ 有 $\mathrm{lfp}\,F=\bigvee_n F^n(\bot)$。这是 `let rec`、递归类型、指称语义（Scott–Strachey）的基础。
- **Scott 连续格 = injective $T_0$ 空间**（Scott）；连续格是"局部紧 sober 空间的开集格"（Hofmann–Lawson 对偶）。
- 代数格的紧元集构成并半格；反之由并半格的理想完备化得回代数格 —— 这是"有限逼近 ↔ 无限对象"的技术核心。

### 分配性的一个真实代价：MFP vs MOP

数据流分析中，
$$\mathrm{MOP}(n)=\bigvee_{\text{path }p\to n}f_p(\iota),\qquad \mathrm{MFP}=\text{迭代不动点解}$$

> **Kildall / Kam–Ullman**：若所有转移函数 $f$ **分配**（$f(x\vee y)=f(x)\vee f(y)$），则 $\mathrm{MFP}=\mathrm{MOP}$（精确）。
> 若 $f$ 仅**单调**，则 $\mathrm{MFP}\sqsupseteq\mathrm{MOP}$ —— 只是安全的过近似。

**常量传播是单调但非分配的经典例子**：$f(x,y)=x+y$，在 $\{x=1,y=2\}\vee\{x=2,y=1\}$ 上，逐支路都得 $x+y=3$（MOP），但先 join 得 $x=\top,y=\top$ 再算得 $\top$（MFP）。

这正是第三节坑 (3) 中"保序但只有 $\ge$"那个间隙的现实版本。**格论层级（分配 vs 仅单调）在这里直接兑换成分析精度。**

## 十一、一句话总结

> **格是"同一个结构的两副面孔"：作为偏序集它有 Hasse 图、链、高度、对偶原理；作为等式代数它是一个 variety，带来同态、同余、自由对象与表示定理。整个理论沿两条轴展开——纵轴是恒等式强度（格 ⊃ 模 ⊃ 分配 ⊃ Heyting ⊃ 布尔，由禁用子格 $N_5,M_3$ 判别，顶端就是幂集格），横轴是完备性/连续性（完备格 ⊃ dcpo ⊃ 连续格，提供 Knaster–Tarski 与 Kleene 迭代）。计算机科学几乎只用两件事：横轴给出"单调算子的不动点存在且可迭代"（终止性、正确性），纵轴给出"精度"（分配 ⇒ MFP=MOP，非分配 ⇒ 只能过近似）。而每个完备格都是某个 $2^Q$ 上闭包算子的不动点格——分配性正是在"闭包后的并不再是并集"这一步失守的。**
